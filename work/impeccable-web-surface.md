# Lexidex Web Library

- Scope: `frontend/index.html`, `frontend/app.js`, `frontend/styles.css`.
- Mode: Operate.
- Audience: the owner curating and consulting a private offline corpus.
- Job: find, filter, inspect, create and maintain terms without modifying the installed package.
- Primary action: add a personal term.
- Proof: live corpus counts, explicit provenance, source links, package/personal distinction and persistent local edits.
- Constraints: localhost, no account, no remote fetch, responsive web companion to Android, package read-only.
- Direction: Archivo de evidencias; a utility rail, ruled index and evidence record replace the prior card-like viewer.
- Memorable moment: selecting a row opens a precise record whose origin and editability are immediately legible.
- Unresolved: richer relationships and content enrichment remain later phases.
